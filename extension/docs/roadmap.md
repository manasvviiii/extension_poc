# Product Roadmap

**Category:** Roadmap  
**Last Updated:** Sep 24, 2026  
**Reading Time:** 6 min read  

Track feature milestones completed to date and planned upcoming platform capabilities.

---

## Completed Milestones

- [x] **Persistent Acquisition**: Acquisition session state persisted across tab navigation and popup closures via `chrome.storage.local`.
- [x] **Background Session**: Persistent `AcquisitionSessionManager` handling background session lifecycle and checkpointing.
- [x] **Humanized Visual Overlay**: Non-interruptive floating UI status overlay on LinkedIn connections pages with status badge, checklist, and minimize/restore.
- [x] **Developer Extraction Dashboard**: Internal QA console for searching, filtering, inspecting raw JSON metadata, and exporting extracted network datasets.
- [x] **Developer QA Console Polish**: Supabase/Linear-style visual health cards, session summary grid, sticky table headers, pagination, and summary JSON exports.
- [x] **Knowledge Hub**: Internal developer documentation portal and engineering knowledge workspace.

---

## Upcoming Planned Features

- [ ] **Graph Readiness Engine**: Automated graph readiness check assessing dataset completeness prior to import.
- [ ] **2nd-Degree Mutual Connection Enrichment**: Deep evidence extraction for mutual connection nodes.
- [ ] **3rd-Degree Multi-Hop Enrichment**: Extended multi-hop graph generation across extended network nodes.
- [ ] **Warm Path Scoring Enhancements**: Advanced ML-weighted relationship scoring combining interaction recency, mutual overlap, and deal relevance.
- [ ] **CRM Sync Connector**: One-click sync with Salesforce and HubSpot for deal team management.
