# Product Roadmap & Engineering Milestones

> [!NOTE] 
> **Status:** Active Roadmap Tracking

This document outlines the engineering journey and release roadmap for WarmGraph.

---

## 🟢 Implemented (v1.0 Core Engine)

- [x] **Persistent Browser Acquisition**: Chrome Extension background session manager.
- [x] **Non-Interruptive Visual Overlay**: 20–25s human-paced observation overlay with friendly state updates.
- [x] **Developer Extraction Dashboard**: Internal QA console for inspecting extracted JSON payload quality.
- [x] **Client-Side Weighted Graph Engine**: Dijkstra shortest warm path calculation.
- [x] **Public SaaS Identity & Knowledge Hub**: Independent documentation workspace and product website.

---

## 🟡 Planned (Q3–Q4 2026)

- [ ] **Multi-Tenant Graph Sync Protocol**: Secure zero-knowledge cloud synchronization for team networks.
- [ ] **2nd & 3rd Degree Network Enrichment**: Automated background resolution of multi-hop bridge profiles.
- [ ] **Warm Path Scoring V2**: Machine learning model trained on deal introduction conversion outcomes.
- [ ] **Institutional CRM Integrations**: Native connectors for Salesforce, HubSpot, and Affinity CRM.

---

## 🔵 Experimental (Research Phase)

- [ ] **AI Deal Sourcing Copilot**: Automated warm introduction blurb generation tailored to target executive profiles.
- [ ] **Real-Time Backchannel Reference Graph**: Verification of confidential executive references.
